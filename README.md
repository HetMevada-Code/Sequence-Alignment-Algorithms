# Sequence Alignment Algorithms

This repository contains Python implementations of two fundamental sequence alignment algorithms used in Bioinformatics.

## Algorithms

### 1. Needleman-Wunsch Algorithm
- Performs Global Sequence Alignment.
- Aligns two sequences over their entire lengths.
- Uses dynamic programming.
- Supports match, mismatch, and gap penalties.

### 2. Smith-Waterman Algorithm
- Performs Local Sequence Alignment.
- Identifies the best matching regions between two sequences.
- Uses dynamic programming.
- Allows zero as the minimum score during matrix filling.
